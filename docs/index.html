Terrarium is a from-scratch scripting sandbox that runs untrusted code without letting it hang you, exhaust your memory, blow your stack, or touch anything you did not hand it. Fuel bounds time, a byte budget bounds allocation, a depth cap bounds recursion, and capabilities gate every effect. For any input script, run returns a value or a typed trap, never a panic, a hang, or an escape. Type a script below, set the limits, choose what to grant, and watch the meters and the trap.

How to use this playground
Write a script, set the limits, choose which capabilities to grant, then run it in the sandbox.
  • Script: type code or pick a preset (normal program, infinite loop, memory bomb, deep recursion, capability escape).
  • Limits: set fuel (steps), memory (bytes), and call depth; lowering them makes the sandbox trap sooner.
  • Granted capabilities: toggle print, input, now, len. Anything ungranted is denied. Watch the verdict and the fuel and memory meters when a limit is hit.

It contains anything you throw at it

The whole project is judged on one claim: for any input script, including adversarial and malformed ones, run returns in bounded time with a value or a typed trap. It never panics the host process, never hangs, never overflows the host stack, and never performs an effect outside the granted capabilities.

# tests/fuzz.rs throws 10,000 programs per run across five fixed seeds,
# with no capabilities granted, and asserts the three invariants
fuzz report: seeds=5 iterations=10000 host_panics=0 hangs=0 escapes=0 traps=9933 values=67

An infinite loop traps OutOfFuel. An allocation bomb traps OutOfMemory before it touches real memory. Unbounded recursion traps StackOverflow instead of a host segfault. An ungranted effect traps CapabilityDenied. Integer overflow wraps, division by zero is a trap, and a garbage source is a clean parse error. tests/containment.rs pins each hostile scenario to its exact trap.

Use it

# build and run the test suite, including the fuzzer and containment gate
cargo build
cargo test

# run a script under limits, granting only what it needs
terrarium run examples/normal.tr --grant print
terrarium run examples/loop.tr --fuel 100000
terrarium run examples/escape.tr
